# Changelog

All notable changes to dsh-retro-mac are documented here.

## [0.1.0] - 2026-08-18

Initial open-source release.

- Two skins — **Platinum** (light) and **Graphite** (dark) — each paired with **Classic Blue** or **System Teal** highlights (4 themes total).
- Full 103-token baseline coverage for the DeepSeek Harness web shell, validated at build time.
- Chicago web font (ChicagoFLF) inlined as base64 — zero external assets.
- Pure-CSS pinstripe desktop wallpaper (no image downloads).
- Beveled Platinum controls: buttons, inputs, square scrollbars with arrow glyphs, menus with hard shadows.
- Barber-pole progress indicators; Happy Mac startup splash easter egg (off by default).
- Settings row (skin / accent / splash), persisted in `localStorage`.
- Bilingual README (English / 中文), MIT license.
